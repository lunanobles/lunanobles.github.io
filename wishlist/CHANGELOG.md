## How this CHANGELOG works
This version of the CHANGELOG will only contain info on updates regarding anything in the `/wishlist` folder. The main CHANGELOG will not contain any information about updates regarding the folder, but WILL still post a "see /wishlist changelog" message if updates occur here.
In the case of a solely /wishlist update, the main CHANGELOG will post a barebones update simply stating "see /wishlist changelog", along with other information as neccisary. In the case of a solely main update, this CHANGELOG will not post any message at all, simply skipping to the next update with relevent updates.
Both lists will ALWAYS share a version ID; the /wishist page will start at 0.6.0 and follow the main as updates occur.
